
0. Scoring rule
===============
Every prompt has a denominator of 3. An attempt counts as a success only
if a human reviewer passed it on replay. Attempts halted because a sibling
had already won score as non-successes like any other -- no arm gets a
smaller denominator. The baseline is now graded on the same terms as the
arms, so all eight are comparable.
arm       attempts  pass/fail judged  invalid  unreviewed  auto-pass -> human-fail  auto-fail -> human-pass
--------  --------  ----------------  -------  ----------  -----------------------  -----------------------
baseline  18        18                0        0           4                        0                      
a1        18        15                3        0           1                        0                      
a2c       18        15                3        0           3                        0                      
a3        18        16                2        0           3                        0                      
a4        18        14                0        4           1                        1                      
a5        18        16                2        0           1                        0                      
a6-2      18        17                1        0           1                        0                      
a6-4      18        15                3        0           3                        0                      

The auto predicate in subtask_completion.py over-grants: 17 of 94 auto-passes
(18.1%, 95% CI [11.6%, 27.1%]) were overturned on review, against
1 auto-fail promoted to a pass. Unreviewed rows fall back to the auto
verdict; only A4 has any, and all four are attempts it never got to finish.
